# React Progressive Dashboard

Ejemplo de una SPA con navegación progresiva, lazy loading, infinite query y
virtualización usando React, Vite, TypeScript, React Router, TanStack Query,
TanStack Virtual, Tailwind, Jest y ESLint.

## Requisitos

- Node.js 20.20.1
- npm 10

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
npm test
```

Las versiones de Node están declaradas en `.nvmrc` y `.node-version`. El proyecto
requiere npm 10 mediante `engines` y registra la versión usada para generar el
lockfile en `packageManager`.
