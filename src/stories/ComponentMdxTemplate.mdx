# Component MDX Template

Use this template when creating documentation files next to a component.

---

## Recommended Location

Save the MDX file in the same folder as the component and story files, for example:

```text
src/components/atoms/Button.mdx
src/components/molecules/Table.mdx
```

---

## Accessibility

### Keyboard Interaction

| Key          | Behavior                            |
|--------------|-------------------------------------|
| `Tab`        | Moves focus to / from the component |
| `Enter`      | Activates the component             |
| `Escape`     | Closes / dismisses (if applicable)  |

### ARIA Attributes

| Attribute        | Usage                                                  |
|------------------|--------------------------------------------------------|
| `role`           | Describe the role, if non-default                      |
| `aria-label`     | Required when there is no visible text                 |
| `aria-disabled`  | Applied when the component is in a disabled state      |
| `aria-expanded`  | Applied when the component controls a collapsible area |

### Guidelines

- Meets WCAG 2.1 AA color contrast requirements.
- Minimum touch target of 44x44px.
- Focus indicator is visible and not suppressed.
- Decorative icons include `aria-hidden="true"`.

## Do's and Don'ts

| Do                                         | Don't                                         |
|--------------------------------------------|-----------------------------------------------|
| Use clear, concise labels                  | Use vague labels like "Click here"            |
| Pair with appropriate variant for context  | Mix variants inconsistently in the same area  |
| Provide accessible names for icon-only use | Rely solely on color to convey meaning        |
