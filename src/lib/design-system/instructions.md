# Design System — How to Use

All design tokens (colors, spacing, fonts, etc.) live in this folder.
You do **not** need to import these files in your components — they are already loaded globally via `src/index.css`.

---

## What's in this folder?

| File | What it is | Can you edit it? |
|------|------------|------------------|
| `index.css` | Wires everything together | No — leave as-is |
| `cds-tokens.css` | Raw CDS `--cds-*` variables (vendored copy of CDS 2.7.0) | **No** — replace on upgrade |
| `app.css` | Fonts, chart colors, UI aliases, legacy classes | Yes |
| `theme.overrides.css` | Stratium-specific Tailwind aliases (brand, ui-*, chart-*) | Yes |
| `theme.generated.css` | Auto-mapped CDS tokens → Tailwind | **No** — regenerated by script |

`cds-tokens.css` is committed here because the CDS package `dist/` folder is gitignored and unavailable in CI.

---

## How to apply tokens in your code

### 1. Tailwind classes (recommended)

Use short class names in JSX:

```tsx
// Colors
<p className="text-brand-primary-main">Title</p>
<div className="bg-background-danger-secondary p-4 rounded-md" />

// Spacing (from CDS space + paragraph + grid)
<div className="p-10 mb-paragraph-5 gap-responsive-desktop-phone-tablet-gutter mx-lg-balanced-margin" />

// Typography styles (font + size + line-height)
<p className="font-body-md text-body-md leading-body-md">Body</p>
<span className="font-tabular-num-bold-italic-md text-tabular-num-bold-italic-md leading-tabular-num-bold-italic-md italic font-bold">
  1,234.56
</span>

// Shadows
<div className="shadow-raised" />
```

**How names map**

| CDS token | Theme key | Short class |
|-----------|-----------|-------------|
| `--cds-color-…` | `--color-…` | `bg-…` / `text-…` |
| `--cds-size-space-10` | `--spacing-10` | `p-10` / `m-10` |
| `--cds-size-paragraph-spacing-5` | `--spacing-paragraph-5` | `mb-paragraph-5` |
| `--cds-size-border-radius-md` | `--radius-md` | `rounded-md` |
| `…-font-family` | `--font-{style}` | `font-{style}` |
| `…-font-size` | `--text-{style}` | `text-{style}` |
| `…-line-height` | `--leading-{style}` | `leading-{style}` |
| `…-paragraph-spacing` | `--spacing-{style}-paragraph` | `mb-{style}-paragraph` |

For weight/style use normal Tailwind: `font-bold`, `italic` (not separate CDS short classes).

### 2. CSS variables (charts, inline styles, Recharts)

Use when Tailwind classes are not enough (e.g. chart `fill`, `stroke`, JS config):

```tsx
// Semantic aliases from app.css
fill="var(--color-chart-risk-high)"
stroke="var(--color-brand-primary-main)"

// Raw CDS variables
color: "var(--cds-color-text-secondary)"
```

### 3. Legacy utility classes (older components)

Still work — defined in `app.css`:

```tsx
<p className="text-brand-primary font-brand">...</p>
<div className="bg-gradient-primary shadow-brand-primary p-4" />
```

Prefer Tailwind classes for new code.

## Quick reference — common tokens

| Use case | Tailwind class | CSS variable |
|----------|----------------|--------------|
| Main brand color | `text-brand-primary-main` | `var(--color-brand-primary-main)` |
| Body text | `text-ui-text-primary` | `var(--color-ui-text-primary)` |
| Muted text | `text-ui-text-secondary` | `var(--color-ui-text-secondary)` |
| Page background | `bg-ui-background-secondary` | `var(--color-ui-background-secondary)` |
| Success | `text-status-success-main` | `var(--color-status-success-main)` |
| Error | `text-status-error-main` | `var(--color-status-error-main)` |
| Chart — high risk | `text-chart-risk-high` | `var(--color-chart-risk-high)` |
| Paragraph gap | `mb-paragraph-5` | `var(--cds-size-paragraph-spacing-5)` |
| Body MD type | `font-body-md text-body-md leading-body-md` | CDS text-body-md-* |
| Space 10 | `p-10` | `var(--cds-size-space-10)` |
| Radius MD | `rounded-md` | `var(--cds-size-border-radius-md)` |

Browse all CDS tokens on the **Manage → Design System** page (`/manage/design-system`).

## When to edit which file

### `theme.overrides.css`
Add or change **Tailwind** token names used as classes.

Example — add a new alias:

```css
@theme {
  --color-my-custom-accent: var(--cds-color-highlight-400);
}
```

Then use: `className="text-my-custom-accent"`

### `app.css`
- Font setup (`@font-face`)
- `:root` variables for charts/components (`--color-chart-*`, `--color-ui-*`)
- Legacy classes (`.text-brand-primary`, `.p-4`, etc.)

## After upgrading CDS tokens

1. Copy the new package CSS into this folder:
   ```bash
   cp lib/cencora-design-system/tokens-2.7.0/package/dist/web/css/index.css src/lib/design-system/cds-tokens.css
   ```
2. Regenerate Tailwind mappings:
   ```bash
   node scripts/generate-cds-theme.mjs
   ```

This updates `cds-tokens.css` and `theme.generated.css`. Your overrides in `theme.overrides.css` and `app.css` are kept.

## Font flash on page load

Brand fonts (Cencora-Gilroy) are **preloaded** automatically:

- **Dev:** Vite injects preload links when you run `npm run dev`
- **Production:** `font-preload-plugin` injects hashed font URLs at build time

The main weights (medium, semibold, bold) use `font-display: block` so the browser waits for the preloaded font instead of showing Arial/Inter first.

If you still see a flash after a CDS upgrade, restart the dev server so preload paths stay in sync.

## How it loads (for reference)

```
src/index.css
  └── src/lib/design-system/index.css
        ├── cds-tokens.css           (raw --cds-* vars, vendored from CDS 2.7.0)
        ├── app.css                  (fonts + semantic vars)
        ├── theme.generated.css      (CDS → Tailwind)
        └── theme.overrides.css      (Stratium aliases)
```

You only work in `app.css` and `theme.overrides.css`. Everything else is automatic.
