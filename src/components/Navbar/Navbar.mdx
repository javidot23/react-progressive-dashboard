# Navbar

A responsive navigation list for switching between related dashboard sections.

---

## When to Use

- Use for a small, stable set of peer sections within the same product area.
- Use link items when navigation should remain addressable through a URL.
- Use button items when selection changes local UI state without navigation.

## When NOT to Use

- Do not use as the application's primary site navigation; use a dedicated global header or sidebar.
- Avoid it for large or deeply nested information architectures; use hierarchical navigation instead.

## Design Tokens Used

| Token | Value | Usage |
|---|---|---|
| Active accent | `violet-600` / `violet-700` | Active border and text |
| Active surface | `violet-50` | Active mobile item background |
| Neutral text | `slate-500` / `slate-950` | Inactive and hover text |
| Touch target | `min-h-11` | Minimum 44px item height |
| Desktop height | `h-16` | Navigation row and disclosure height |
| Item radius | `rounded-md` | Mobile item corners |

## Accessibility

### Keyboard Interaction

| Key | Behavior |
|---|---|
| `Tab` | Moves focus through the disclosure and navigation items |
| `Enter` / `Space` | Opens the mobile disclosure or activates a button item |
| `Enter` | Follows a link item |
| `Escape` | Closes the mobile disclosure and returns focus to its trigger |

### ARIA Attributes

| Attribute | Usage |
|---|---|
| `aria-label` | Gives the navigation landmark an accessible name |
| `aria-controls` | Connects the mobile disclosure to the controlled list |
| `aria-expanded` | Announces whether the mobile list is open |
| `aria-current` | Identifies the active link item |
| `aria-pressed` | Identifies the active button item |
| `aria-hidden` | Hides decorative icons from assistive technology |

### Guidelines

- Keep labels short, unique, and descriptive.
- Provide `ariaCurrent="location"` when links identify locations within one page.
- Maintain the 44px minimum touch target when overriding classes.
- Do not rely on the active color alone; the border and ARIA state also communicate selection.

---

## Do's and Don'ts

| Do | Don't |
|---|---|
| Keep the number and order of items stable | Use the Navbar for an unbounded list |
| Match each active ID to exactly one item | Mark multiple items as active |
| Use links for addressable destinations | Replace native link behavior with buttons |
| Keep decorative icons hidden from assistive technology | Use icons without visible text labels |
