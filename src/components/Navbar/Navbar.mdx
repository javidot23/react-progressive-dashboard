# Navbar

A responsive navigation list for switching between related sections.

## Mobile presentations

Use the default `mobileMode="disclosure"` when the navigation should collapse
behind a labeled trigger. Use `mobileMode="horizontal-scroll"` for persistent
tab-style navigation that remains in one scrollable row. When `activeId`
changes, the horizontal mode scrolls only its own list far enough to keep the
active item visible.

## Accessibility

### Keyboard Interaction

| Key | Behavior |
|---|---|
| `Tab` | Moves focus through the disclosure and navigation items |
| `Enter` / `Space` | Opens the mobile disclosure or activates a button item |
| `Enter` | Follows a link item |
| `Escape` | Closes the mobile disclosure and returns focus to its trigger |

### ARIA Attributes

| Attribute | Usage |
|---|---|
| `aria-label` | Gives the navigation landmark an accessible name |
| `aria-controls` | Connects the mobile disclosure to the controlled list |
| `aria-expanded` | Announces whether the mobile list is open |
| `aria-current` | Identifies the active link item |
| `aria-pressed` | Identifies the active button item |
| `aria-hidden` | Hides decorative icons from assistive technology |

### Guidelines

- Keep labels short, unique, and descriptive.
- Provide `ariaCurrent="location"` when links identify locations within one page.
- Keep horizontal-scroll navigation inside a width-constrained parent so overflow remains local to the list.
- Maintain the 44px minimum touch target when overriding classes.
- Do not rely on the active color alone; the border and ARIA state also communicate selection.
